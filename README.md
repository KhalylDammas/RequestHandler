# Request Management System

This system allows you to:

- Create (add)
- View
Your requests.

## Setup

This program setup is very simple

### Step 1: Setup a new virtual environment

Create a virtual environment:

```zsh
python -m venv .venv
```

Activate the venv:

```zsh
source .venv/bin/activate
```

### Step 2: Run the program

```zsh
python main.py
```
